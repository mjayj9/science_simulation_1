# 형상 프리셋과 비교 계약

## 공통 기준

형상 비교의 고정 기준은 **총 활성면적**이다. 비교용 평면·정육면체·구·원기둥·원뿔 프리셋은 20개의 전기 구역을 가지며, 구역 하나의 활성면적은 `0.0025 m²`, 총 활성면적은 정확히 `0.050 m²`다. 셀 효율, 온도계수, IAM, 인버터, 회로 토폴로지, 바이패스 조건, 위치, 시간, 기상, 장애물과 난수 시드는 형상 사이에서 공유한다. 형상별 보정계수나 순위 보정 multiplier는 사용하지 않는다.

| 프리셋 | 기하 모델 | 전기 구역 |
|---|---|---|
| 평면, 정육면체 | `0.05 m × 0.05 m` 강체 평판 | 강체 패널 20장 |
| 구, 원기둥, 원뿔 | 빈틈없는 이상적 유연 PV 스킨 | 연속 표면을 면적 기준으로 나눈 20개 구역 |
| 자유 조립 | `0.05 m × 0.05 m` 강체 평판 | 사용자가 1~20장 구성 |

곡면의 20개 구역은 렌더링 삼각형이나 20장의 접평면 사각형이 아니다. `ScenePanel` 형태의 대표 위치와 법선은 선택, 색상, 회로 식별자와 진단 UI를 위한 anchor일 뿐이며 광학 계산은 구역 내부 표면 표본을 적분한다.

투영면적은 입력 조건이 아니라 형상과 태양 방향으로부터 나오는 결과다. 비교 화면은 다음 값을 서로 바꾸어 쓰지 않는다.

- 활성면적 `A = 0.050 m²`
- 현재 태양 방향의 투영면적
- 가능한 최대 투영면적
- 지면 footprint
- 순간·누적 발전량과 활성면적당·투영면적당·footprint당 정규화 값

## 연속 곡면의 공통 면적 좌표

구, 원기둥 옆면, 원뿔 옆면은 누적면적 좌표 `q ∈ [0,1]`와 방위각 `φ ∈ [0,2π)`를 공통 매개변수로 사용한다.

\[
dA=\frac{A}{2\pi}\,dq\,d\phi
\]

전기 구역 `j=0,…,19`는 `q ∈ [j/20,(j+1)/20]`인 **전 방위 band**다. 따라서 모든 구역 면적은 해석적으로 `A/20 = 0.0025 m²`이며, band 사이에 틈이나 중복 활성면적이 없다.

각 구역은 `q` 방향 2점 Gauss–Legendre 적분과 방위 방향 `Nφ`개 주기 중점 적분을 사용한다. 구역당 표본 수는 `2Nφ`, 표본 하나의 면적 가중치는 `0.0025/(2Nφ) m²`다. 현재 품질 단계의 `Nφ`는 빠름 16, 균형 32, 정밀 64이며 API 허용 범위는 16~128의 정수다. 이 물리 격자는 Three.js 렌더링 tessellation과 독립적이다.

## 구

구는 닫힌 완전 구면이며 전체 표면이 활성 PV 스킨이다.

\[
R=\sqrt{\frac{A}{4\pi}}\approx0.06308\ \mathrm{m}
\]

`q`에서 `n_y = 2q-1`이고 위치는 `p = c + Rn`이다. 법선은 삼각형 법선이 아니라 항상 해석식 `n=(p-c)/R`로 계산한다. Gauss–Legendre 표본은 극점 `q=0,1`에 직접 놓이지 않는다.

완전 구의 임의 방향 직달 투영면적은 다음과 같이 일정하다.

\[
A_{proj}=\pi R^2=\frac{A}{4}=0.0125\ \mathrm{m^2}
\]

따라서 태양을 정면으로 보는 동일 면적 평면의 최대 직달 자원은 구의 약 4배가 될 수 있다. 이는 보정할 오차가 아니라 형상 자체의 광학 결과다.

## 원기둥

원기둥은 월드 Y축을 중심축으로 하는 옆면만 활성화한다. 위·아래 원판은 렌더링과 발전면적에서 제외한다. 세로비 `k=h/(2r)`를 지정하면 면적 보존 치수는 다음과 같다.

\[
A=2\pi rh,\qquad r=\sqrt{\frac{A}{4\pi k}},\qquad h=2rk
\]

누적면적 좌표는 `y = h(q-1/2)`이고, 법선은 Y 성분이 0인 반지름 방향이다. 단위 태양 방향 `s`의 수평 성분을 `|s_h|`라 하면 옆면 투영면적은 `2rh|s_h|`, 최대값은 `2rh`다.

## 원뿔

원뿔은 월드 Y축을 중심축으로 하는 옆면만 활성화하고 밑면은 제외한다. 세로비 `k=h/r`를 지정하면 다음 식이 적용된다.

\[
\ell=\sqrt{r^2+h^2}=r\sqrt{1+k^2},\qquad
A=\pi r\ell,
\]

\[
r=\sqrt{\frac{A}{\pi\sqrt{1+k^2}}},\qquad h=kr
\]

면적은 빗면 거리의 제곱에 비례하므로 빗면 분율은 `√q`다. 적분점은 꼭짓점에 직접 놓이지 않으며, 법선은 `h/ℓ`의 수평 성분과 `r/ℓ`의 상향 성분을 갖는 해석 법선이다. 한쪽 면만 발전하는 원뿔 옆면의 투영면적은 해석식을 사용하고, 최대 투영면적은 태양 고도 0~90°에서 결정론적으로 최적화한다.

## 회전 불변성과 적분

모든 회전은 오른손 좌표계의 월드 Y축 회전 하나로 표면 위치와 법선에 함께 적용한다. 렌더링 표면, 구역 경계, 선택 표본 helper에도 같은 각도를 정확히 한 번만 적용해야 한다.

구·원기둥·원뿔은 모두 Y축 회전체다. 장애물이 없고 공간적으로 균일한 일사 조건에서는 Y축 자전으로 총 투영면적이나 총 광학 입력이 변하지 않아야 한다. 런타임의 투영면적 원장은 유한 표본합 대신 해석적 축대칭 적분을 사용해 가짜 회전 ripple을 만들지 않는다. 유한 표본 적분은 별도 수렴 테스트에서 방위 위상과 `Nφ=32 → 64` 변화에 대한 오차를 제한한다.

장애물, 비대칭 가시율, 비균일 오염처럼 환경 자체가 축대칭이 아니면 회전 불변 조건은 성립하지 않는다.

## 전기적 공정성 모드

두 모드는 같은 광학·온도 계산에서 동시에 산출된다.

- **Mode A — 동일 회로(`shared-circuit`)**: 20개 구역에 같은 직렬/병렬 토폴로지, 바이패스 다이오드와 인버터를 적용한다. 구역별 입사각 차이로 생기는 전류 불일치와 바이패스 동작을 포함한다.
- **Mode B — 형상 광학(`independent-mppt`)**: 각 `0.0025 m²` 구역의 MPP를 독립적으로 합산한 뒤 같은 인버터 모델을 적용한다. 직렬 불일치와 바이패스 손실은 0으로 두지만 투영, IAM, 외부 차폐, 오염과 온도 효과는 유지한다. 이는 구역마다 이상적인 optimizer가 있다는 상한 비교다.

손실 원장은 태양 직달 자원에서 투영면적, IAM, 외부 차폐, 자체 차폐, 오염, 온도·PV 모델, mismatch, 바이패스와 인버터 손실을 순서대로 추적한다. 바이패스 손실은 전체 회로 손실의 부분 귀속이며 mismatch와 중복 차감하지 않는다. 현재 볼록한 연속 스킨의 뒷면 제외는 투영기하에서 이미 반영되므로 `selfShadingLossW`는 별도 추가 차감 없이 0이다.

## 렌더링과 상호작용 계약

곡면 프리셋은 하나의 고해상도 연속 mesh로 그린다. 20개 등면적 구역 경계는 별도 선 layer이고, 선택 구역의 표면 표본·해석 법선·태양광선·AOI 호는 진단 helper다. 이 시각 요소의 개수나 해상도는 활성면적 또는 물리 적분 가중치를 변경하지 않는다.

제작 가능성, 실제 셀 분할과 배선, 차폐 근사와 장기 계산 경로의 범위는 [알려진 한계](known-limitations.md)를 따른다.
