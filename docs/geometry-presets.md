# 패널 형상 프리셋

## 공통 규격과 좌표

모든 패널은 `0.05m × 0.05m`, 면적 `0.0025m²`의 단단한 정사각형 평판이다. 크기 조절은 허용하지 않으며 전면만 발전한다. 패널 로컬 `+Z`가 전면 법선이고, 저장되는 quaternion `[x,y,z,w]`에서 월드 법선을 다시 계산한다.

월드 좌표는 `+X=동`, `+Y=상`, `+Z=북`이다. 태양 방위는 북 0°, 동 90°이고 공통 회전축은 `+Y`다. 기본 패널 간격은 `0.01m`, 중심 pitch는 `0.06m`다. 다섯 공학 프리셋은 생성 직후 패널 수가 정확히 20인지 검사한다.

## 정육면체

- 아래쪽 `-Y`를 제외한 `+Y`, `±X`, `±Z` 다섯 면을 사용한다.
- 각 면에 2×2, 총 20개를 놓는다.
- 기본 cube 한 변은 `2×0.05 + 3×0.01 = 0.13m`다.
- 각 면 중심에서 두 접선축으로 `±0.03m` 이동한 위치가 패널 중심이다.
- 법선은 해당 면 바깥 방향이고 모서리에는 5mm 여유가 남는다.

아래 면을 비우므로 지면 방향 패널이 추가 발전하는 일이 없다. 면 사이 패널은 서로 다른 평판이며 cube 표면으로 구부리지 않는다.

## 일반 평면

- 기본 배열은 4행×5열이다. 선택적으로 5×4를 만들 수 있다.
- 기본 tilt는 30°, 방위는 180°(남향)이다.
- 법선은 `(sinγ sinβ, cosβ, cosγ sinβ)`로 만든다.
- 법선과 직교하는 두 접선축에 0.06m pitch로 중심 정렬한다.
- 4×5 배열의 패널 외곽 크기는 기본 약 `0.29m × 0.23m`다.

경사와 방위는 전체 평면 법선을 바꾸며 각 패널의 quaternion과 cached normal은 항상 일치해야 한다.

## 원기둥

- 반지름 `0.12m`의 네 높이 ring에 각각 5개를 놓는다.
- ring 높이는 `-0.09, -0.03, 0.03, 0.09m`다.
- 각 ring은 72° 간격이고 패널 중심은 원주 위에 있다.
- 법선은 수평 반지름 방향 `(sinφ,0,cosφ)`이다.

패널은 원기둥 곡면을 따르는 곡판이 아니라 접하는 평판이므로 패널 사이에 의도적인 틈이 있다.

## 구

- 반지름 `0.18m` 구면에 Fibonacci sphere로 20개 중심을 분포한다.
- `yi = 1-2(i+0.5)/N`, `ri=sqrt(1-yi²)`, `φi=iπ(3-√5)`를 사용한다.
- 중심은 `0.18×(ri cosφi, yi, ri sinφi)`다.
- 법선은 중심의 단위 반지름 방향이다.

Fibonacci 분포는 위·경도 ring보다 극점 밀집을 줄이는 결정론적 근사다. 유한한 20점에서 정확히 동일한 최근접 거리를 보장하지 않는다.

## 원뿔

- base radius `0.18m`, height `0.28m`의 원뿔 옆면을 사용한다.
- 아래에서 위로 8·6·4·2개인 네 ring, 총 20개를 놓는다.
- 원뿔 좌표 높이는 `0.035 + 0.065k m`, 화면 중심은 전체 높이의 절반만큼 내린다.
- 해당 높이 반지름은 `r=0.18(1-y/0.28)`이다.
- 바깥 법선은 `normalize(sinφ, 0.18/0.28, cosφ)`다.
- 홀수 ring은 반 칸 회전해 세로 정렬 중첩을 줄인다.

모든 패널은 원뿔 접평면과 평행한 평판이다. 꼭짓점에는 패널을 배치하지 않는다.

## 자유 조립

자유 조립 문서는 1~20개 패널을 허용한다. 초기 배치는 20개 평면 배열이며 다음 명령은 원본 배열을 변경하지 않고 새 배열을 반환한다.

- `addPanel`: 20개 제한과 ID 고유성 검사
- `duplicatePanel`: 기본 0.06m offset으로 복제
- `deletePanel`: 최소 1개 유지
- `updatePanel`/`transformPanel`: 위치와 정규화 quaternion 갱신, 법선 재계산

드래그 미리보기와 저장 commit을 분리하면 한 번의 드래그가 undo 한 단계와 자동 저장 한 번이 된다.

## 겹침 검사

패널은 기본 두께 `0.0005m`의 oriented bounding box로 바꾸고 15축 separating-axis test를 수행한다. 접촉만 한 경우는 겹침으로 보지 않으며 기본 허용오차는 `1e-6m`다. 결과는 충돌한 두 패널 ID 쌍이다.

이 검사는 편집 경고용이다. 프레임·볼트·케이블의 실제 조립 공차나 구조 충돌을 검증하지 않는다.

## 차폐 가시율

1. 패널 전면을 `N×N` cell 중심으로 표본화한다. 기본은 3×3, 범위는 1~15다.
2. 표본을 전면 법선으로 `1e-5m` 이동해 자기 교차를 막는다.
3. 표본에서 태양 단위벡터 방향으로 ray를 보낸다.
4. 다른 패널의 유한 사각형 또는 장애물의 월드 AABB와 가장 가까운 교차를 찾는다.
5. `Vsun=가시 표본 수/전체 표본 수`를 반환한다.

`n·s≤0`인 뒷면 입사는 차폐와 관계없이 가시율 0이다. 화면의 shadow map은 이 계산에 쓰지 않는다. 회전된 장애물은 여덟 모서리를 변환한 보수적 월드 AABB를 사용하므로 복잡 형상에서 실제보다 차폐가 클 수 있다.

## 비교 장면 규칙

최대 5개 형상, 총 100개 패널을 허용한다. 각 형상은 같은 시간·태양·기상·환경·seed를 받지만 물리 장면은 독립적이다. 화면에서 나란히 보인다는 이유로 다른 비교 형상이 광선을 막지 않는다. 절대 W/Wh와 함께 패널 수·총면적 및 W/m²·Wh/m²를 표시한다.
