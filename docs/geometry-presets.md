# 형상 프리셋과 비교 계약

## 기본 비교와 레거시 편집기의 경계

기본 형상 비교는 평면·정육면체·원기둥·구·반구·원뿔을 각각 **하나의 빈틈없는 이상적 연속 PV 스킨**으로 계산한다. 모든 형상에는 같은 수평 직교투영면적 `A_land`가 주어지고, `A_PV`는 형상의 해석적 표면적에서 나온다. 기본 화면에는 20개 panel/zone, `N_eq`, 동일 활성면적 전환, Mode A/B 또는 사용자가 그린 회로가 들어가지 않는다.

`5 cm × 5 cm` 강체 패널, 1~20장 제한, 직렬·병렬 회로와 바이패스 다이오드는 **자유 조립 및 이전 프로젝트 호환 경로**의 계약이다. 이 경로는 유지되지만 기본 동일 토지 비교와 결과를 섞지 않는다. 소스에 남아 있는 `ELECTRICAL_ZONE_COUNT`, `PANEL_AREA_M2`, `electricalFairnessMode` 및 선택적 `basis: "active"`도 그 레거시·진단 경로의 회귀 호환용이며 기본 비교의 물리 분할이 아니다.

| 구분 | 기본 동일 토지 비교 | 자유 조립·호환 경로 |
|---|---|---|
| 물리 객체 | 형상당 연속 스킨 1개 | 강체 패널 또는 이전 곡면 구역 |
| 면적 기준 | 공통 `A_land`, 형상별 `A_PV` | 사용자가 만든 패널 수·기존 활성면적 |
| 전기 계산 | `local-mpp-area-integral` | 단순/단일 다이오드, 직렬·병렬, 바이패스, 선택적 공정성 모드 |
| 기본 worker 입력 | `continuousSurface.samples[]` | `panels[]`, `panelCount`, 회로 입력 |
| UI 용도 | 여섯 형상 공정 비교 | 설계·회로 실험과 이전 문서 재현 |

## 공통 면적과 수치 적분

비교 형상은 해석 기하에서 표본 위치 `x_i`, 바깥쪽 단위법선 `n_i`, 절대 면적 가중치 `ΔA_i`를 만든다.

```text
Σ ΔA_i = A_PV
P_DC(t) = Σ [η_PV(T_i(t)) · POA_i(t) · ΔA_i]
```

곡면은 누적면적 좌표 `q∈[0,1]`와 방위 좌표 `φ∈[0,2π)`를 쓰며, 면적 좌표에서는 다음처럼 적분한다.

\[
dA=\frac{A_{PV}}{2\pi}\,dq\,d\phi
\]

비교 전용 기본 구적법은 `q` 방향 8개 구간마다 2점 Gauss–Legendre, 방위 방향 `Nφ`개 주기 중점 표본을 사용한다. 품질 단계의 `Nφ`는 빠름 16, 균형 32, 정밀 64이며 허용 범위는 16~128이다. 평면과 정육면체도 같은 절대면적 표본 계약을 사용한다. Three.js 렌더 삼각형 수는 이 물리 적분 해상도와 무관하다.

`zones`라는 내부 배열은 기존 `SurfaceIntegrationModel` 타입과 진단 렌더러를 재사용하기 위한 **매개화 영역**이다. 기본 비교에서 영역 수는 평면 1, 정육면체 5면, 구 1, 반구 1, 원기둥 2(윗면/옆면), 원뿔 1이며 전기 직렬 구역이 아니다. worker 직렬화 시 영역 경계를 풀어 하나의 절대면적 표본 배열로 보내므로 영역끼리 전류를 제한하거나 각자 MPPT를 갖지 않는다.

## 형상별 해석 기하

아래 식은 고정 평면, 간격 0, 활성면적 상한에 걸리지 않는 일반 비교 기준이다. `R=√(A_land/π)`이고 원기둥과 원뿔의 기본 높이는 `H=2R`다.

| 형상 | `A_land` 정의 | 활성면적 `A_PV` | 활성 표면 |
|---|---|---|---|
| 평면 | `w l cosβ` | `w l=A_land/cosβ` | 경사진 직사각 스킨 |
| 정육면체 | `s²` | `5s²=5A_land` | 윗면과 네 옆면, 바닥 제외 |
| 구 | `πR²` | `4πR²=4A_land` | 완전 구면 |
| 반구 | `πR²` | `2πR²=2A_land` | 상향 곡면, 밑면 원판 제외 |
| 원기둥 | `πR²` | `πR²+2πRH` | 윗면 원판과 옆면, 밑면 제외 |
| 원뿔 | `πR²` | `πR√(R²+H²)` | 옆면, 밑면 제외 |

기본값 `A_land=0.050 m²`, `β=30°`, `H=2R`에서 활성면적은 다음과 같다.

| 평면 | 정육면체 | 원기둥 | 구 | 반구 | 원뿔 |
|---:|---:|---:|---:|---:|---:|
| 0.057735 | 0.250000 | 0.250000 | 0.200000 | 0.100000 | 0.111803 m² |

### 평면

고정 평면은 위에서 볼 때 `L×L` 정사각 footprint를 유지한다. `L=√A_land`, 경사방향 길이는 `L/cosβ`, 따라서 `A_PV=A_land/cosβ`와 전체 수직 높이 `L tanβ`를 얻는다. 기본 `A_land=0.050 m²`, `β=30°`에서는 footprint 폭·깊이 `0.223607 m`, 경사길이 `0.258199 m`, 높이 `0.129099 m`다. 경사각의 공유 입력 계약은 0~75°이며 UI도 같은 범위를 사용한다. 범위 밖 입력은 조용히 75°로 바꾸지 않고 명시적 오류로 거부하며, 범위 안의 각도가 `H_max` 또는 활성면적 제한을 초과할 때만 가능한 최대 각도로 제한한다.

동일 `A_land` 기본 비교의 평면 자세는 **fixed**로 고정한다. 단축·이축 추적은 순간 수평투영이 시간에 따라 변하고, 고정 `A_PV`의 강체 추적과 시점마다 표면을 다시 만드는 해석을 혼동할 수 있으므로 기본 순위에 포함하지 않는다. protocol과 기하 라이브러리에 남은 tracking adapter는 별도 추적 설계·레거시 실험용이다.

### 정육면체

한 변은 `s=√A_land`다. 다섯 활성면은 수치 적분을 위한 다섯 매개화 영역이지만 전기적으로 분리된 다섯 패널이 아니다. 아래 면은 활성면적과 발전량에서 제외한다.

### 구와 반구

구의 해석 법선은 항상 `n=(x-c)/R`이고 임의 태양 방향에서 직달 투영은 정확히 `πR²=A_land`다. 반구는 `n_y≥0`인 상향 곡면만 사용한다. 태양 단위벡터의 수직 성분을 `s_y`라 하면 반구의 직달 투영은 `A_land(1+s_y)/2`다.

### 원기둥

윗면과 옆면은 결과 원장을 위한 `top`, `lateral` 영역으로 보존한다. 윗면 법선은 `+Y`, 옆면 법선은 수평 반지름 방향이다. 직달 투영은 다음과 같다.

\[
A_{sun}=\pi R^2\max(0,s_y)+2RH\lVert s_h\rVert
\]

두 영역의 DC를 따로 인버터에 넣는 것이 아니다. 국소 DC를 모두 합쳐 공통 인버터를 한 번 적용한 뒤, 영역별 연간 AC는 같은 비율로 귀속하고 합계가 전체와 닫히도록 한다.

### 원뿔

빗면 거리 표본은 면적이 반지름 제곱에 비례하는 점을 반영해 누적면적 좌표의 제곱근으로 배치한다. 꼭짓점 자체에는 구적점을 놓지 않으며, 법선은 삼각형 근사가 아니라 원뿔 해석 법선이다.

## 투영면적, footprint와 회전

`A_land`는 비교 정규화에 쓰는 형상의 월드 `XZ` 직교투영 합집합 면적이다. 기본 여섯 형상은 이 값과 `requestedLandAreaM2`가 같아 면적지수 `100`을 갖는다. 축 정렬 bounds의 면적은 회전한 직사각형에서 실제 합집합보다 클 수 있으므로 `A_land`로 대체하지 않는다.

현재 자세의 정적 투영, 360° Y축 회전의 swept footprint와 간격을 포함한 parcel은 별도 값이다. 비축대칭 형상의 swept footprint가 `A_land`보다 큰 것은 숨기지 않고 제약 진단으로 표시하지만 연간 에너지의 `kWh/m²-land/year` 분모를 조용히 바꾸지는 않는다. 구·반구·원기둥·원뿔은 Y축 회전체이므로 장애물이 없는 균일 환경에서 Y축 자전에 따른 총 광학 출력이 불변이어야 한다. 평면의 태양 추적 swept envelope는 별도 설계 경로에서만 평가한다.

## 렌더링과 선택

비교 형상은 연속 mesh로 그린다. 표면 법선과 적분 표본 helper는 계산 계약을 설명하는 시각 요소이며, helper 개수나 렌더 tessellation을 바꾸어도 `A_PV`와 발전량이 바뀌어서는 안 된다. 자유 조립의 강체 패널 선택·TransformControls·회로 ID는 별도 편집 경로에만 적용한다.

수치 결과와 구형 결과의 비교는 [동일 토지 비교 보고서](land-area-comparison-report.md), 제조·전기 이상화는 [알려진 한계](known-limitations.md)를 따른다.
