# 패널 형상 프리셋

## 공통 규격과 비교 기준

모든 패널은 `0.05 m × 0.05 m`, 면적 `0.0025 m²`인 단단한 정사각형 평판이다. 모든 기본 형상은 20장을 사용하므로 총 활성면적은 `0.050 m²`로 같다. 패널 로컬 `+Z`가 전면 법선이고, 월드 좌표는 `+X=동`, `+Y=위`, `+Z=북`이다.

형상 비교의 1차 공정성 기준은 패널 수, 개별 패널 면적, 총 활성면적, 패널 물성 및 태양·기상 조건을 같게 유지하는 것이다. 투영 단면적은 태양 방향과 형상에 따라 달라지는 성능 변수이므로 형상마다 강제로 같게 만들지 않는다. 같은 활성면적과 같은 투영 단면적을 동시에 요구하면 평면 형상에서는 패널을 겹치거나 일부를 제거해야 하므로 비교 목적과 충돌한다.

기본 패널 간격 `g`는 `0.001 m`이고 중심 pitch는 `p = 0.05 + g = 0.051 m`이다.

## 정육면체

- 아래쪽 `-Y`를 제외한 `+Y`, `±X`, `±Z`의 5개 면을 사용한다.
- 각 면에 2×2장씩 총 20장을 둔다.
- 한 변은 `2 × 0.05 + g`로 계산해 가장자리의 불필요한 여백을 제거한다.

## 일반 평면

- 기본 배열은 5×4이며 4×5도 선택할 수 있다.
- 경사각과 방위각으로 전체 평면 법선을 정한다.
- 법선과 직교하는 두 접선축에 pitch `p`로 패널 중심을 정렬한다.

## 원기둥

- 기존 5장×4단 대신 10장×2단을 사용해 원주 방향의 큰 빈틈을 줄인다.
- 정십각형의 접선면이 맞닿는 조건에서 반지름을 역산한다.
- `r = p / (2 tan(π/10))`
- 각 패널 법선은 수평 반지름 방향이며 세로 중심 간격은 `p`다.

## 구

- 20개의 법선은 정십이면체 꼭짓점 방향에 둔다. 이 배치는 각 방향의 최근접 각거리가 동일하다.
- 정십이면체 꼭짓점의 최소 각도는 `θmin = acos(√5/3)`이다.
- 중심 간 chord가 패널 pitch에 가깝도록 `r = 1.05p / (2 sin(θmin/2))`로 반지름을 계산한다.
- 기본값에서 반지름은 약 `0.075 m`이며, 이전 고정 반지름 `0.18 m`보다 크게 작아진다.
- 명목 구면 피복률 `20A/(4πr²)`은 약 70%다. 정사각형 20장으로 양의 가우스 곡률을 가진 구면을 빈틈과 겹침 없이 완전 타일링하는 것은 불가능하므로, 작은 비정형 틈은 남는다.

## 원뿔

- 아래에서 위로 8·6·4·2장인 4개 ring을 사용한다.
- 정사각형의 위쪽 모서리가 더 작은 원주로 모이면서 겹치는 현상을 피하기 위해 taper 배율 `k = 1.3`을 적용한다.
- 모선 방향 pitch를 `kp`, 모선 길이를 `4kp`로 둔다.
- 첫 ring의 반지름은 `r₀ = kp / (2 tan(π/8))`이며, 여기서 밑면 반지름과 높이를 역산한다.
- 각 ring의 중심을 모선 방향으로 `0.5kp`, `1.5kp`, `2.5kp`, `3.5kp`에 놓는다. 이는 OBB 충돌이 없는 범위에서 빈틈을 최소화한 값이다.

## 자유 조립과 충돌 검사

자유 조립은 1~20장의 패널을 허용한다. 추가·복제·이동·회전·삭제는 원본 배열을 변경하지 않는 명령으로 처리한다. 충돌 검사는 두께 `0.0005 m`인 oriented bounding box와 15축 separating-axis test를 사용한다. 모든 기본 프리셋은 자동 테스트에서 패널 수, 크기, 정규화된 법선·quaternion, 곡면 프리셋의 무충돌 및 조밀도를 검증한다.

## 차폐 가시율

패널 전면을 격자로 표본화하고 각 표본에서 태양 방향으로 광선을 보낸다. 다른 패널이나 장애물의 AABB가 광선을 먼저 가로막으면 그 표본을 차폐로 계산한다. `n·s ≤ 0`인 후면 입사에서는 가시율을 0으로 둔다. 렌더링 그림자는 시각화용이며, 발전량 계산은 이 수치 raycast 결과를 사용한다.

## 비교 장면 규칙

최대 5개 형상, 총 100장의 패널을 비교할 수 있다. 각 형상은 같은 시간·태양·기상·환경·난수 seed를 사용하지만 물리 장면은 독립되어 서로를 차폐하지 않는다. 결과에는 절대 W/Wh와 총 활성면적으로 정규화한 W/m²·Wh/m²를 함께 표시한다.
