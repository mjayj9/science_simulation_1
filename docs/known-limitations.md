# 알려진 한계

이 문서는 결과의 적용 범위를 명시한다. 테스트 통과와 브라우저 계산 완료는 아래 이상화 안에서의 소프트웨어 계약을 뜻하며 제품 인증, 구조 안전 검토 또는 발전량 보증을 뜻하지 않는다.

## 기본 비교의 모델 경계

- 기본 비교의 여섯 형상은 각각 하나의 빈틈없는 `ideal-continuous-skin`이다. 실제 셀 크기, 절단, 간격, 프레임, busbar, 배선과 봉지재 곡률을 생성하지 않는다.
- 기본 비교에는 20개 panel/zone, `N_eq`, 동일 활성면적 모드 또는 Mode A/B가 없다. 형상 내부의 `surface`, `top`, `lateral`, cube face는 수치 매개화·보고 영역일 뿐 전기 구역이 아니다.
- `5 cm × 5 cm` 강체 패널, 1~20장 제한, 회로·바이패스와 선택적 공정성 모드는 자유 조립 및 이전 프로젝트 호환 경로에 남는다. 그 결과를 기본 동일 토지 비교 결과로 표시하지 않는다.
- 구·반구·원기둥·원뿔은 늘어날 수 있는 이상적 유연 스킨이다. 완전 구면을 평평한 셀로 빈틈없이 덮을 수 있다는 제조 가능성을 주장하지 않는다.
- 비교 `A_land`는 형상의 수평 직교투영 합집합이다. 회전 swept footprint, 축 정렬 bounds와 간격을 포함한 parcel은 별도 진단값이며 토지 정규화 분모를 자동으로 대체하지 않는다.
- 평면·고체가 `H_max` 또는 활성면적 제약을 만족하지 못할 때 실제 설계 최적화를 수행하지 않는다. 구현된 제한·거부 규칙은 비교 기하를 유한하게 만드는 계약이다.

## 수치 적분

- 물리 적분은 절대면적 가중 표본을 사용하고 `ΣΔA=A_PV`를 검사한다. 기본 균형 품질은 누적면적 방향 8구간×GL2와 방위 `Nφ=32`다.
- 유한 구적은 좁은 그림자 경계, 빠른 우회전, 매우 작은 구조물이나 불연속 입력에서 추가 수렴 검사가 필요하다. 선택한 clear-day/대표일 회귀의 0.5% 기준을 모든 기상·차폐에 대한 보증으로 확대하지 않는다.
- Three.js mesh 해상도는 물리 구적과 분리되어 있다. 매끄럽게 보이는 렌더 표면이 자동으로 더 정확한 발전량을 뜻하지 않는다.
- 원기둥의 윗면·옆면 AC는 전체 표면의 합산 DC에 적용된 공통 인버터 수용 비율을 영역별 DC에 배분한 귀속값이다. 영역마다 실제 독립 MPPT나 인버터가 있다는 뜻이 아니다.

## 복사와 차폐

- POA는 직달, Hay–Davies 또는 등방 하늘 산란, Lambert 지면반사를 사용한다. Perez 전천구, 파장 의존, 다중반사, 적설과 주변 구조물의 복사 교환은 포함하지 않는다.
- IAM은 ASHRAE 또는 physical 근사다. 실제 유리·코팅·곡률의 측정값이 있으면 기본 계수 대신 검증된 자료를 사용해야 한다.
- 외부 장애물은 정규화된 정적 AABB의 직달 ray 교차로 근사한다. 실제 GLB/GLTF 삼각형, 오목부, 세밀한 실루엣과 태양 원반에 의한 반그림자는 계산하지 않는다. AABB는 실제 형상보다 보수적으로 크게 가릴 수 있다.
- 장애물 ray는 직달 성분에만 적용한다. 곡면 자체의 등방 sky/ground view factor는 해석 법선의 `(1±n_y)/2`를 사용하지만 장애물이 가리는 sky dome과 지면을 다방향 ray로 적분하지 않는다.
- 볼록한 한쪽 발전면은 `max(0,n·s)`로 뒷면 직달을 제외한다. 오목 구조, 지지부재의 자체 그림자, 반투명 스킨과 내부 상호차폐는 지원하지 않는다.
- `reflectorMode=none`이어도 지면 albedo에 의한 Lambert 반사는 남는다. 흰색·알루미늄 옵션은 면적 예산이 있는 확산 등가 모델이며, 알루미늄 정반사 집광이나 연구컵의 실제 3D ray 집중을 재현하지 않는다.

## 국소 MPP와 인버터

- 기본 비교는 각 미소 면적에서 `ηPV(T)×POA×dA`를 국소 이상 MPP로 보고 합산한다. 국소 DC 결합 과정에 전압·전류 mismatch, bypass, 배선 저항 또는 optimizer 변환손실이 없다고 가정한 상한이다.
- 각 미소 면적의 DC는 단순 효율·온도계수 모델이다. 무한개의 단일 다이오드 I–V 곡선을 풀어 공통 버스에서 결합한 모델이 아니다.
- 합산 DC에는 하나의 인버터 모델을 적용한다. 버스 전압은 패널·스트링 개수 없이 인버터 MPPT 범위와 전류 한계에 맞추는 이상적 결합 규칙이므로 실제 컨버터 설계가 아니다.
- 기본 비교에서 mismatch loss와 bypass count가 0인 것은 형상에 불일치가 물리적으로 없다는 관측 결과가 아니라, 해당 회로 소자를 모델 계약에서 제외했다는 뜻이다.
- 자유 조립의 단일 다이오드, 회로와 PVWatts형 인버터도 정상상태 근사다. 셀 열화, hotspot 열결합, avalanche, dynamic MPPT, 계통 전압·주파수 응답과 보호기기 협조를 포함하지 않는다.
- Faiman 온도는 정상상태이고 열용량, 장파복사 하늘온도, 빗물 냉각과 곡면 내부 열전도를 생략한다. 풍속 높이 보정은 평균 프로파일이며 CFD가 아니다.

## 회전과 추적

- 회전은 구조 전체의 월드 Y축 강체 회전이다. 표본 위치와 법선은 같은 변환을 받지만 베어링, 관성, 유체-구조 연성과 발전에 필요한 구동전력은 없다.
- 축대칭 형상의 회전 불변성은 균일 일사와 장애물 없는 조건에서만 성립한다. 비대칭 AABB 장애물이나 공간적으로 다른 오염이 있으면 회전에 따라 출력이 달라질 수 있다.
- 고정 RPM 구간은 주기 위상 적분으로 평균한다. 좁은 차폐 이벤트에는 위상 표본 수를 높여 별도 수렴을 확인해야 한다.
- 동일 토지 기본 비교의 평면은 fixed다. 단축·이축 tracking adapter는 별도 설계·레거시 경로에만 남으며 기본 형상 순위에 사용하지 않는다. 그 별도 경로도 backtracking, 행간 음영 최적화, 구동 한계, stow 풍속과 구동 에너지를 포함하지 않는다.

## 시간, 날씨와 worker

- Open-Meteo, PVGIS와 NASA 자료는 위치의 계측기 실황과 다를 수 있다. provenance, 원본 timestamp, 공간·시간 해상도를 함께 확인해야 한다.
- 선호 series가 요청 시간축을 완전히 덮지 못하면 전 구간을 결정론적 offline series로 대체한다. 경계 spike를 피하는 대신 사용 가능한 일부 외부 자료도 버리는 보수적 정책이다.
- offline clear 시계열은 Haurwitz/Erbs 기반 결정론적 시나리오이며 관측·예보·TMY 보증자료가 아니다. 낮은 태양 고도와 GHI-only 분해에서 오차가 커질 수 있다.
- 연간 worker는 8,760개 시간 구간에 closing endpoint를 더한 timestamp 경계를 사용한다. 일간 10분 그래프나 12개 대표일 추정과 해상도·적분 계약이 같지 않다.
- fingerprint가 다른 worker chunk와 완료 이벤트는 폐기한다. 이 보호는 잘못된 결과 재사용을 막지만 사용자가 입력을 바꾼 뒤 이전 계산을 다시 기다리지 않아도 된다는 뜻은 아니다.

## 진단과 UI

- 원인코드는 임계값 기반 감사 label이며 인과 추론 모델이 아니다. 여러 코드가 동시에 붙을 수 있고 코드 자체는 발전량을 변경하지 않는다.
- 기본 비교 화면에서 숨긴 20구역·Mode A/B 문구가 자유 조립 또는 이전 상세 진단 화면에는 남을 수 있다. 화면의 모델 badge와 worker fingerprint를 확인해야 한다.
- 실제 브라우저 8,760시간 실행은 수동으로 확인했지만 매 커밋에서 자동 수행되는 E2E 수치 회귀는 아니다.
- 연속 mesh의 틈, 표본 helper, top-view footprint와 hit-test를 픽셀 단위로 고정하는 시각 회귀는 아직 없다.

## 적합한 사용과 부적합한 사용

적합한 용도는 공통 입력에서 이상적 형상의 상대 비교, `A_land`와 `A_PV` 정규화 분리, 투영·복사 성분 진단과 입력 민감도 탐색이다. 부적합한 용도는 투자 수익 보증, 제조 가능성 판정, 구조·전기 안전 승인, 계통연계 시험과 실시간 제어 명령이다.

형상과 기본 전기 계약은 [형상 프리셋](geometry-presets.md), 실제 결과와 레거시 차이는 [동일 토지 비교 보고서](land-area-comparison-report.md), 시간축 원인코드는 [입사각·시간 진단](incident-angle-diagnosis.md)을 참고한다.
