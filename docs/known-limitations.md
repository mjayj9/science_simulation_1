# 알려진 한계

이 문서는 현재 버전의 계산 범위와 사용자에게 반드시 공개해야 할 한계를 정리한다. “지원”은 모델을 계산할 수 있다는 뜻이며, 실측·인증 도구와 동일한 정확도를 보장한다는 뜻이 아니다.

## 태양과 복사

- 태양 위치 코어는 NOAA/Meeus 천문력을 NREL SPA 입력·방위 규약에 맞춘 축약 구현이다. NREL의 2003 SPA 기준 사례를 약 0.1° 수준으로 검사하지만 완전한 SPA 다주기 급수와 ±0.0003° 불확도를 주장하지 않는다.
- GHI만 있을 때 Erbs로 DNI/DHI를 분해한다. 천정각 87° 이상, 매우 짧은 구름 변동, 적설 반사 상황에서 오차가 커질 수 있다.
- 경사면 산란광은 Hay–Davies/등방 성분을 사용한다. Perez 전천돔의 세부 밝기 분포, 다중 반사, 주변 구조물의 파장별 반사는 생략한다.
- 지면은 균일한 Lambert 반사체로 본다. 수면 정반사와 지형별 비균일 알베도는 표현하지 않는다.
- IAM은 physical 또는 ASHRAE 모델이다. 실제 모듈 유리·코팅 제조사 데이터가 있으면 기본 계수 대신 그 값을 사용해야 한다.

## 음영과 3D 장면

- 패널은 5cm 정사각형의 불투명 단면 평판이다. 프레임 두께, 셀 간격, 리본, 반투명 모듈은 모델링하지 않는다.
- 수치 차폐는 패널 표면의 유한한 표본 격자를 사용한다. 작은 장애물은 표본 사이를 통과할 수 있으므로 정확도 설정을 높이고 수렴을 확인해야 한다.
- UI 장애물과 가져온 GLB/GLTF의 빠른 차폐 경계는 보수적인 AABB 근사를 사용할 수 있다. 회전된 복잡 형상의 삼각형 실루엣과 정확히 일치하지 않으며 화면의 렌더링 그림자를 발전량으로 사용하지 않는다.
- 하늘 가시율과 지면 가시율은 전천구 ray 적분이 아닌 실시간 근사다. 반투명 나뭇잎, 회절, 태양 원반 크기와 penumbra를 생략한다.
- 겹침 검사는 0.5mm 두께의 oriented box와 SAT를 사용한다. 실제 패널 프레임·체결구의 기계 간섭 검토를 대신하지 않는다.

## 온도·환경·공기역학

- Faiman 온도는 정상상태 모델이다. 모듈 열용량, 순간 열과도, 복사 하늘온도, 야간 장파 과냉각을 생략한다.
- 높이별 풍속은 중립 로그 프로파일 근사다. 대기 안정도, 열부력, 복잡 산악 지형, 도시 협곡은 별도 CFD/현장 풍황 없이 정확히 재현할 수 없다.
- 환경 장애물 후류는 공학적 감쇠이며 CFD가 아니다. 난류 강도는 3D 와류장을 생성하지 않는다.
- 회전 토크는 준정상 평판 항력과 공통 +Y축 강체 운동이다. lift, dynamic stall, 유체-구조 연성, 베어링 stick-slip, 패널 상호 후류를 생략한다.
- 회전 결과는 구조 하중·피로·안전성 판정이 아니라 발전량 민감도 비교용이다.

## 전기와 인버터

- 단일 다이오드 모델은 정상상태 단접합 PV를 가정한다. 셀 역항복, hotspot 열전파, 눈/균열/열화의 셀별 효과는 포함하지 않는다.
- 바이패스는 패널 또는 정의된 그룹의 piecewise 순방향 전압으로 처리한다. 다이오드 온도·동특성·avalanche는 생략한다.
- 회로 해석은 지원되는 직렬·병렬·바이패스 구조에 최적화되어 있다. 임의 SPICE 회로, 접지 고장, 아크, 보호기기 협조와 계통 단락 계산은 지원하지 않는다.
- 인버터는 PVWatts V5 대표 효율곡선·MPPT 범위·전류 제한·클리핑 근사다. 제조사별 multi-MPPT 제어, 동적 스캔, 계통 전압/주파수 응답은 포함하지 않는다.
- 풍력 발전 전력은 계산하지 않는다. 바람은 패널 온도와 형상 회전에만 영향을 준다.

## 시간·연간 결과와 성능

- 일간은 선택한 시간 간격의 순간 전력을 사다리꼴 적분한다. 시간평균 API 값은 원래 구간 의미를 확인해야 하며 간격을 줄여 수렴을 점검해야 한다.
- 연간 실행 전 화면의 월간값은 12개 대표일을 실제 모델로 적분한 빠른 추정이다. `연간 8,760시간점 계산`을 실행하면 전용 worker가 오프라인/API 시간별 시계열을 다시 계산해 월·연간 AC값을 교체한다. 어느 쪽도 장기 현장 계측, 가동중단, 적설, 열화, 청소 일정, 계통 출력제한을 모두 포함한 금융성 수율은 아니다.
- 일간·대표일 고RPM 계산은 빠름 12, 균형 24, 정밀 72개 위상으로 평균해 aliasing을 줄인다. 연간 worker의 고정 RPM은 현재 시간별 위상을 직접 평가하므로 특정 RPM/시간격자 조합은 결과 수렴을 별도로 확인해야 한다.
- 연간 계산은 실제 전용 worker에서 POA·온도·PV·회로·인버터와 사다리꼴 적분을 실행하고 fingerprint, 진행률, 취소, stale 결과 차단을 제공한다. 다만 연간 worker는 현재 GLTF/장애물의 시간별 ray 장면을 전달받지 않으므로 복잡 차폐는 순간·일간 결과에서 더 충실하다.
- 일반 데스크톱의 5형상/100패널을 목표로 하지만 대형 GLTF, 높은 표본 격자, 고밀도 차트는 GPU·메모리에 따라 느려질 수 있다.

## 기상·외부 데이터

- Open-Meteo current는 관측소 실측이 아니라 모델값이다. 모델·격자·업데이트 시각이 바뀌면 동일 위치 결과도 달라질 수 있다.
- PVGIS는 공식 CORS 제한 때문에 정적 앱에서 직접 AJAX 조회하지 않는다. 공식 URL로 받은 파일 가져오기가 기본 경로다.
- NASA POWER는 위성·재분석 격자 자료이며 현장 관측을 대신하지 않는다. 브라우저 CORS는 배포 origin에서 별도 확인이 필요하다.
- API 오류·CORS·잘못된 스키마에서는 결정론적 오프라인 시계열로 전환한다. 이 값은 실제 날씨가 아니라 `모델 추정값`으로 표시해야 한다.
- 오프라인 날씨 프리셋의 구름·비는 시나리오 생성용이며 예보가 아니다.

## 저장과 파일 이동성

- 자동 저장은 현재 브라우저 프로필의 기기 로컬 저장이다. 로그인 동기화, 서버 백업, 공동 편집은 제공하지 않는다.
- 시크릿 모드, 사이트 데이터 삭제, 저장 용량 제한으로 데이터가 사라질 수 있으므로 중요한 프로젝트는 JSON으로 내보내야 한다.
- 브라우저는 원래 로컬 파일 경로를 다시 열 수 없다. 저장 라이브러리는 GLB/GLTF Blob용 IndexedDB 계층을 제공하고 현재 화면 JSON은 파일명 참조를 보존한다. 다른 기기 또는 JSON만 이동한 경우 파일 재연결이 필요할 수 있다.
- V1→V2→V3 마이그레이션은 알려진 필드만 변환한다. 미래 버전은 조용히 강등하지 않고 가져오기를 거부한다.

## 적합한 사용과 부적합한 사용

적합한 사용은 형상 간 상대 비교, 입력 민감도 확인, 수업·연구 프로토타이핑, 모델 추적이다. 부적합한 사용은 발전소 보증치, 금융 모델의 단독 근거, 구조·전기 안전 인증, 제품 형식시험, 실시간 제어 명령이다.

더 상세한 공식별 범위는 [모델링 조사](modeling-research.md), 데이터 제약은 [기상 데이터 소스](data-sources.md)를 참고한다.
