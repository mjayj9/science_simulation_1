# 알려진 한계

이 문서는 계산 결과의 적용 범위를 명시한다. 테스트 통과는 아래 이상화 가정 안에서의 소프트웨어 계약을 뜻하며, 제품 인증이나 발전소 성능 보증을 뜻하지 않는다.

## 형상과 곡면 적분

- 평면·정육면체·자유 조립은 `5 cm × 5 cm` 강체 평판 모델이다. 프레임, 셀 간격, 리본, 봉지재와 후면 구조는 모델링하지 않는다.
- 구·원기둥·원뿔은 면적을 보존하며 늘어나거나 변형될 수 있는 **이상적 유연 PV 스킨**이다. 완전 구면은 평평한 정사각형 셀을 무변형으로 감아 만들 수 없으므로 실제 제조 배치가 아니다.
- 곡면의 20개 전기 구역은 누적면적 좌표의 전 방위 band다. 각 band의 면적은 정확하지만 실제 셀 절단, busbar, 배선 길이와 전극 저항을 재현하지 않는다.
- 물리 적분은 각 band에서 `q` 방향 2점과 방위 방향 유한 `Nφ`를 사용한다. 현재 회귀는 선택한 태양 방향의 순간 POA 수렴을 검증하며, 모든 기상·차폐에서 일일 에너지 0.5%를 보장하지 않는다.
- Three.js mesh 해상도는 물리 적분과 분리되어 있다. 매끄럽게 보이는 표면이 자동으로 더 정확한 물리 결과를 뜻하지 않는다.

## 복사와 차폐

- POA는 직달, Hay–Davies 또는 등방 하늘 산란, Lambert 지면반사를 사용한다. Perez 전천구, 다중 반사, 주변 구조물의 파장별 반사와 적설은 포함하지 않는다.
- IAM은 ASHRAE 또는 physical 모델이다. 실제 유리·코팅·곡률의 측정 자료가 있으면 기본 계수 대신 검증된 값을 사용해야 한다.
- 외부 장애물 가시율은 정규화된 AABB proxy의 직달 ray 근사다. 복잡한 GLB/GLTF의 실제 삼각형, 오목부와 세밀한 실루엣은 worker에 전달하지 않는다. 곡면 표본의 산란광 sky-view와 지면 view factor는 별도 ray 적분 없이 1을 사용한다.
- 구·원기둥·원뿔은 볼록한 한쪽 발전면으로 다루며 `max(0,n·s)`가 뒷면 직달광을 제외한다. 이 효과는 투영면적에 포함되므로 손실 원장의 자체 차폐 항목은 0이다. 오목 구조, 구조부재에 의한 자체 그림자와 반투명 스킨은 지원하지 않는다.
- 태양 원반 크기와 penumbra를 생략한다. 표본 수와 장애물 경계에 따라 작은 물체의 그림자가 계단형으로 바뀔 수 있다.

## 전기·열·인버터

- 곡면 표본의 POA와 온도는 면적 적분되지만, 구역 전기 모델은 적분된 유효 POA와 온도로 하나의 I–V 곡선을 만든다. 한 구역 내부의 미세한 셀 mismatch와 hotspot은 해석하지 않는다.
- Mode A는 동일 회로·바이패스·인버터 비교다. 바이패스 손실은 전체 회로 불일치 손실의 부분 귀속이며 별도 추가 손실로 이중 차감하지 않는다.
- Mode B는 각 `0.0025 m²` 구역에 이상적 독립 MPPT가 있다는 상한 모델이다. 실제 optimizer 효율, 기동조건, 배선과 통신 손실은 추가하지 않는다.
- 단일 다이오드, 단순 DC와 PVWatts형 인버터는 정상상태 모델이다. 셀 열화, hotspot 열결합, avalanche, dynamic MPPT, 계통 전압·주파수 응답과 보호기기 협조를 포함하지 않는다.
- Faiman 온도는 정상상태이며 열용량, 장파복사 하늘온도, 빗물 냉각과 곡면 내부의 열전도를 생략한다. 풍속 높이 보정은 평균 프로파일 근사이며 CFD가 아니다.

## 회전

- 회전은 구조 전체의 월드 Y축 강체 회전이다. 샘플 위치와 법선은 같은 행렬을 받지만 lift, dynamic stall, 베어링 stick-slip, 유체-구조 연성은 없다.
- 축대칭 곡면의 회전 불변성은 균일 일사와 장애물 없는 조건에서만 성립한다. 비대칭 장애물이나 공간적으로 다른 오염이 있으면 회전에 따라 출력이 변할 수 있다.
- 고정 RPM 구간은 주기 위상 적분으로 평균한다. 품질 단계의 유한 위상 수 때문에 불연속 전기 이벤트와 매우 좁은 차폐 이벤트에는 추가 수렴 검사가 필요하다.
- 풍력 발전 전력과 구조 하중·피로·안전 판정은 계산하지 않는다.

## 시간, 날씨와 worker

- Open-Meteo 값은 관측소 실황이 아니라 모델/예보 자료일 수 있고 PVGIS·NASA 자료도 공간·시간 평균이다. provenance와 원본 timestamp를 함께 확인해야 한다.
- 선호 series가 전체 요청 시계를 덮지 못하면 전 구간을 오프라인 series로 대체한다. 이 정책은 자료 경계 spike를 피하지만, 부분적으로 이용 가능한 실측/API 구간까지 버리는 보수적 선택이다.
- 오프라인 series는 결정론적 시나리오 생성값이며 예보나 관측이 아니다. GHI-only 분해와 매우 낮은 태양 고도에서는 DNI/DHI 오차가 커질 수 있다.
- 현재 일간 차트는 10분, 대표월 계산은 1시간 간격을 사용한다. 연간 worker는 시간점 경계와 구간 평균 계약을 사용하며 모든 UI 그래프와 같은 해상도는 아니다.
- UI의 연간 요청은 각 곡면 zone의 GL2×`Nφ` 표본과 면적 가중치를 worker에 전달한다. 따라서 연간 광학·온도 경로도 대표 anchor가 아니라 표면 적분을 사용한다. 월별 bucket은 `reportingOffsetMinutes`로 선택한 현지 시간대 경계에 맞추되 물리 timestamp는 UTC다.
- UI는 ground/water를 제외한 동일 장애물 AABB를 연간 variant에 전달하고, worker는 Y 회전된 강체 pose와 곡면 sample 위치에서 직달 ray 가시율을 적용한다. 이 경로는 회귀 테스트로 고정되어 있다. 다만 AABB proxy는 실제 GLB 삼각형 차폐보다 보수적일 수 있고, 산란광 sky-view와 지면 view factor는 여전히 별도 모델이 아니다.
- fingerprint가 다른 worker 이벤트는 폐기하고 `STALE_WORKER_RESULT`를 연간 감사 경고로 표시한다. 이는 일간 차트 행의 원인코드와는 별도 상태다.

## 진단과 UI

- 원인코드는 임계값 기반 감사 label이며 인과 추론 모델이 아니다. 하나의 시점에 여러 코드가 함께 붙을 수 있고, 코드 임계값은 발전량을 변경하지 않는다.
- 일간 그래프 점 클릭과 상세 진단 카드는 구현되어 있지만 브라우저 상호작용 자동 테스트는 아직 없다.
- 곡면 renderer와 조립 화면은 연속 mesh, zone 경계, 선택 표본 helper 토글과 곡면 hit-test를 연결한다. 빈틈, 경계 정합과 회전 helper를 픽셀 기준으로 확인하는 시각 회귀는 아직 없다.

## 적합한 사용과 부적합한 사용

적합한 용도는 동일 입력에서의 형상 상대 비교, 투영면적과 회로 mismatch 분해, 입력 민감도 탐색, 교육·연구 prototype이다. 부적합한 용도는 금융 수익 보증, 제품 인증, 구조·전기 안전 승인, 계통연계 시험과 실시간 제어 명령이다.

형상 정의는 [형상 프리셋](geometry-presets.md), 시간 급변과 원인코드는 [입사각·시간 진단](incident-angle-diagnosis.md), 자동화 범위는 [검증 결과](validation-report.md)를 참고한다.
