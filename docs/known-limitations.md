# 알려진 한계

이 문서는 계산 결과의 적용 범위를 설명한다. 테스트와 감사 통과는 명시된 수학·수치 계약이 구현됐다는 뜻이며, 제품 인증·구조 안전 검토·발전량 보증을 뜻하지 않는다. 최신 계산 수치는 [자동 생성 검증 보고서](generated-validation-report-2026.md)를 따른다.

## 기하와 제조 가능성

- 여섯 공식 형상은 빈틈없는 곡면 PV skin의 해석 모델이다. 곡면에 실제 셀을 절단·봉지하는 공정, 프레임, busbar, 케이블 routing, 지지부재와 유지보수 통로를 자동 설계하지 않는다.
- `A_land`는 정적 수평투영 또는 비정적 360° swept occupation 계약이다. 실제 부지에는 행간, 접근로, 안전 이격, 지형과 상호 음영을 포함한 더 큰 parcel이 필요할 수 있다.
- `H_max=2√(A_land/π)`는 형상 비교용 공정 외피이지 구조 안정성·풍하중·좌굴·피로 기준이 아니다.
- 유한 구적은 좁은 그림자 경계와 빠른 회전에서 해상도 민감도를 가진다. Three.js 렌더 mesh를 세분해도 물리 구적이 자동으로 정밀해지지 않는다.

## 광학과 환경

- POA는 직달, 선택한 하늘 산란 근사와 Lambert 지면반사를 사용한다. 파장 의존 광학, 다중반사, 적설, 오염의 공간 변화, 태양 원반 penumbra와 주변 구조물의 장파 상호복사는 일반 경로에 없다.
- 장애물은 정적 AABB의 직달 ray 차폐다. 실제 삼각형 실루엣, sky-dome 차폐와 세밀한 자체음영을 대체하지 않는다.
- 반사판 옵션은 면적·반사율 예산이 있는 등가 모델이다. 특정 연구의 cup reflector나 정반사 집광 geometry를 자동 재현하지 않는다.
- offline weather fixture는 결정론적 모델 추정값이며 계측 서울 TMY나 발전 보증자료가 아니다. 외부 자료를 쓸 때도 provenance, 공간·시간 해상도와 누락 구간을 확인해야 한다.

## 이상적 상한과 공학적 전기 연결

- `local-mpp-area-integral`은 모든 미소면이 독립 MPPT를 갖는 이상적 연속막 상한이다. 실제 단일 곡면 모듈의 직렬 불일치·bypass·배선손실과 동일하지 않다.
- `explicit-series-parallel-bypass`는 같은 명목 셀 밀도와 명시적 직렬·병렬·bypass substring을 사용하지만, 사용자가 정한 등가 topology다. 제조사별 셀 형상, busbar, optimizer, 셀 편차, hotspot-avalanche, 열화와 dynamic MPPT를 완전히 모델링하지 않는다.
- 공통 인버터는 정적 등가 모델이다. 계통 전압·주파수, 보호협조, clipping 제어의 시간응답과 보조전력 공급원을 설계하지 않는다.
- 모터 소비가 gross AC보다 큰 순간의 net 발전은 0으로 제한된다. 별도 motor ledger는 필요한 전기 수요를 보여주지만 계통 수전원을 자동으로 모델링하지 않는다. 풍력 발전 전기는 제외한다.

## 준정상 열과 annual transient

- 준정상 Faiman 경로는 timestamp 사이 온도상태를 보존하지 않는다. 이 결과는 반드시 `준정상 광학 회전·열이력 미포함`으로 해석한다.
- annual transient는 실제 weather clock에서 열상태를 유지하고 별도 저해상도 열노드망을 쓴다. 열용량, 흡수 일사, 전기 추출, 장파복사, 양면 대류와 인접 노드 전도를 포함하지만, 상세 적층재·접촉저항·내부 유동·비/증발·CFD는 대체하지 않는다.
- 열노드망은 광학 구적망과 분리돼 있으므로 감사 fixture의 mesh 수렴 결과를 다른 형상·기상·차폐 해상도에 무조건 일반화할 수 없다.
- warm-up/주기 수렴은 초기온도 민감도를 줄이지만 실제 전년도 말의 알려지지 않은 열상태를 측정한 것은 아니다.
- 현재 annual transient opt-in은 `local-mpp-area-integral` 연속표면만 지원한다. 공학적 전기 연결, 외부 장애물 또는 plane tracking과의 결합은 검증 단계에서 거부된다. 해당 조합에 과도열 결과가 있다고 해석하면 안 된다.
- transient variant의 streamed 시간행은 준정상 진단이고, authoritative 월·연간 에너지는 complete event의 E11이다. 두 경로를 하나의 시계열처럼 혼합하지 않는다.

## 회전과 공력

- 통제 RPM은 모든 형상에 같은 사용자가 지정한 운동학 속도를 적용한다. 관성·시동·탄성·진동·피로를 예측하는 모터/구조 동역학 해석은 아니다.
- 자연 RPM은 기상 구간별 ODE 적분 결과지만 정확도는 형상별 `C_Q(λ)`, 마찰, 공기저항, 관성과 풍속 profile 자료의 품질을 넘지 못한다. 난류 CFD와 유체-구조 연성은 포함하지 않는다.
- source-backed 자가기동 `C_Q`가 없는 대칭 형상의 공식 자연 RPM은 0이다. 사용자 `C_Q`를 넣은 값은 low-confidence sensitivity이며 측정 예측으로 승격하지 않는다.
- 별도 비대칭 수동 로터의 footprint·높이·음영이 빠지면 그 sensitivity는 공식 토지 비교에서 제외된다. 현재 감사의 사용자-C_Q 보조로터 사례가 이에 해당한다.
- `|u_wind-ω×r|`는 회전 표면의 상대풍속을 반영하지만 국부 난류, 박리, 방향별 압력분포와 형상별 대류 상관식의 실험 보정을 대신하지 않는다.
- 축대칭 형상의 광학 회전 불변성은 장애물·방향성 반사·공간적으로 다른 오염이 없는 조건에 한정된다.

## 시간 적분과 결과 종류

- 실제 전년 감사는 비윤년 8,760개 또는 윤년 8,784개 구간과 closing endpoint를 요구한다. 마지막 경계점은 중복 발전시간이 아니다.
- 대표일 결과는 진단·민감도 결과다. 대표일 환산과 실제 전년 시간 적분을 같은 순위 또는 같은 열이력으로 섞으면 안 된다.
- 빠른 회전 구간의 위상 구적, 날카로운 차폐 사건과 비선형 풍속 토크는 추가 해상도 수렴이 필요할 수 있다.
- 자연 RPM은 `solve(mean wind)`가 아니라 각 기상 구간의 동역학을 적분한 시간가중 평균이다. 두 연산은 비선형 토크 때문에 일반적으로 같지 않다.

## 연구 재현 범위

- 연구 A–D는 source-equivalent 실행에 필요한 상세 형상·기상·전기·열 경계가 부족해 `not-evaluated`다. 검증 성공 건수에 포함하지 않는다.
- source E의 pass는 convex sphere의 direct-beam 기하/광학 적분을 검증한다. PV 전기·온도·연간 기상 재현은 아니다.
- source F의 pass는 보고된 rotating heated disk 조건에서 Reynolds/Nusselt 계산을 검증한다. PV laminate의 연간 회전냉각을 직접 검증한 것은 아니다.
- 연구 benchmark의 허용오차와 조건 일치·불일치는 [1차 출처 재현 감사](research-source-equivalent-audit.md)에 기록된다. 일반 형상 순위가 논문 경향과 비슷하다는 사실만으로 재현 성공을 선언하지 않는다.

## 적합한 해석

적합한 용도는 명시된 공통 조건에서 토지 생산성, PV 면적당 생산성과 이상적 상한을 분리해 비교하고 입력 민감도를 탐색하는 것이다. 투자수익 보증, 제조 가능성 판정, 구조·전기 안전 승인, 계통연계 시험과 실시간 제어 명령에는 사용하지 않는다.
